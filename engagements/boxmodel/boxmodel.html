Box Model

  1. What is the difference between block tags and inline tags?

    Block tags start on a new line and take up the full width of the page and inline tags stay inside a line of text and only take up as much width as their content needs

    Example of Block Tags (header, h1, ol, li, ul)
    Example of Inline Tags: Span Text, Strong Text, Example link

  2. What is the margin, border, and padding?

    Border is the visible line that goes around the padding and content.

    Margin is the empty space outside the border that pushes other elements away.

    Padding is the space inside the box, between your content and the border.

  3. What are units of measurement you can use in CSS?

    CSS uses different units to measure sizes and spacing for example the pixels(px).

  4. When would you use a figure tag?

    You use the "figure" tag when you want to group an image together with its caption using "figcaption". It gives the image its own block layout so it looks neat and organized.
