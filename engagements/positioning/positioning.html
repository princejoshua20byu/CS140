Positioning

Questions and Answers

1. What is normal flow in HTML?

Normal flow is how elements appear on a webpage in their usual order, from top to bottom.

2. What does float do? Why clear the float?

Float moves an element to the left or right so text can wrap around it. Clear makes the next content move below the floated element.

3. What do absolute, fixed, and relative do?

Relative moves an element from its normal position. Absolute lets you place an element in a specific spot. Fixed keeps an element in the same place on the screen, even when you scroll.

4. How can you make navigation buttons for phones?

I can use display: block; and add padding so the links are easier to tap on a phone.
