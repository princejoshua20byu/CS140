Questions and Answers

1. What does the action attribute do?

The action attribute tells the form where to send the information after the user clicks the submit button.

2. What does the method attribute do?

It tells the browser how to send the information from the form. The two common methods are GET and POST.

3. What is the difference between POST and GET?

GET is when you can see all the information in the website like when you are reading or searching while POST is for private informations like password and emails.

4. How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

A preset value is information already filled in when the page opens. A placeholder can already see the box.

  • Text box: Use value for preset text and placeholder for a hint.
  • Textarea: Put preset text between the opening and closing tags.
  • Select box: Use selected to choose an option by default.
  • Checkbox: Use checked to select it by default.
  • Radio button: Use checked to select an option by default.

5. List all the form controls that HTML5 added. Which ones did you put in your form?

HTML5 added new input types such as email, date, datetime-local, month, number, range, search, tel, time, url, week, and color.

In my form, I used email, date, and number. These controls make it easier for users to enter information.
