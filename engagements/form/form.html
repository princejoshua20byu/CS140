Questions and Answers

1. What are different ways to style your form?

There are different ways to style a form using CSS. We can change the colors, font, borders, spacing, and background. We can also use padding and margin to make the form look organized.

2. Why does the professor like to use flex?

Flex is useful because it helps arrange items in a row or column. It also makes it easier to organize labels and input fields. We can use it to make the form look neat and organized.

3. What makes for a good mobile form?

A good mobile form should be easy to read and use on a small screen. The input fields should fit the screen, and the labels should be easy to understand. The buttons should also be easy to tap.
