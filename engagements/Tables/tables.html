1. Why don't we use the border attribute? We don't use the border attribute because CSS is better for styling a table. It is easier to change the design using CSS.

2. What is the easiest way to color every other row a different color? The easiest way is to use :nth-child() in CSS. It helps us color every other row without adding a class to each row.

3. What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select. The value inside the parentheses tells CSS which row to select. For example, even selects the 2nd, 4th, and 6th rows. We can also use odd to select the 1st, 3rd, and 5th rows.
