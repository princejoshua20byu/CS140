The Definitions

1. Internet a worldwide internet that connects all the computers and devices

2. Web is the collection of websites and web pages that can access through the internet

3. Internet vs. Web - the internet is the network and the web is the service that shows websites.

4. ASCII and Unicode. ASCII is a system that gives number to basic english letters, number and symbols. Unicode is a system that supports characters from all languages.

5. UTF-8 a common way to store and display Unicode character oin computers and websites.

6. URL is the address of a webpage or file on the internet.

7. Domain Name is the easy to read name of a website.

8. HTTP is a set of rules used to send webpages between a web server and a browser.

9. HTTPS is a secure version of HTTP.

10. IP Address is a number that identifies a device on a network.

11. DNS is a system that changes domain names into IP addresses so computer can find websites.

12. W3C Recommendations created by world wide web consortium to help websites work correctly in different browsers.

13. XML is a language used to organize and store data. XHTML is a stricter version of HTML that follows XML rules. HTML is the main language used to create the structure of webpages. HTML5 is the modern version of HTML, it supports video,audio, and other webpage features.
