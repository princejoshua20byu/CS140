Different ways to select items are:

  1. Tag Name - Selects an HTML tag (p{color:red;})
  2. ID- Selects one element with a specific ID.(#header{color:blue;})
  3. Class - Select elements with the class.(.menu{color: green})
  4. Children - Selects an elements inside another element. (div p{color:black;})

Difference between an ID and a Class is that ID is used for one specific element and class can be used for many elements.

Difference between SPAN and the SPAN is used for small part of text or an inline item and the DIV is used for a larger section or group of content.


Difference between DIV and HEADER, MAIN, or FOOTER is nothing
