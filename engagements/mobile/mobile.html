First Assignment Questions

1. Why is the viewport meta tag important?

The viewport meta tag helps the website fit on different screen sizes, like phones, tablets, and computers.

2. How can you adjust the CSS for printing?

We can use @media print to change how the website looks when we print it.

3. When would you want to adjust the CSS for printing?

We adjust the CSS for printing when we want the page to look better on paper and use less ink.

Second Assignment Questions

Write down at least three things that look wrong or are hard to use.

The sidebar is on the top instead of the main content. The main content is not centered on the phone screen. The images inside the cards are not the same size on the phone.

1. Why do we need a viewport meta tag?

The viewport meta tag helps our webpage fit the screen of a phone or tablet. Without it, the page might look too small, and we need to zoom in to read it.

2. When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

The rule that comes later usually takes priority if both have the same specificity. For example, if I put column at the bottom of my CSS, the items will stack vertically. If I put row at the bottom, the items will be side by side.

3. How do you change the CSS for a web page displayed on a phone?

I can use media queries to change how my webpage looks on a phone. I can adjust the cards, images, and navigation so they fit better on a smaller screen.

4. Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

One website I use on my phone is YouTube. On my phone, the videos are shown in one column, and the navigation is easier to use. On a computer, I can see more videos because the screen is bigger.

5. What width did you choose for your breakpoint, and why?

I chose 680px for my breakpoint because my webpage starts to look crowded at a smaller screen size. The sidebar and cards do not have enough space, so I use a media query to make the layout better for phones.
