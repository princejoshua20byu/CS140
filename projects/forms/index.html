Questions and Answers

1. What is JavaScript? How did it get its name?

JavaScript is a programming language used to make websites interactive. It was first called LiveScript, but its name was changed to JavaScript.

2. What are the two ways you can run JavaScript?

You can run JavaScript in a web browser or on a server using Node.js.

3. What is jQuery? Is it still popular today?

jQuery is a JavaScript library that makes it easier to work with websites. Yes, people still use it, but it is less popular for new projects today.

4. What is the most popular front-end JS library today?

React is one of the most popular JavaScript libraries used to build websites and user interfaces.

5. How does your code prevent the form from being submitted? Why do we need to prevent it?

My code uses event.preventDefault() to stop the normal form submission. We need it so JavaScript can check and collect the information without reloading the page.
