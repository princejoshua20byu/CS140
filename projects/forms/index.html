AJAX Questions and Answers

1. What is AJAX?

AJAX is a way for a website to send and receive data without reloading the whole page. In my activity, AJAX gets the response from submit.json and displays the message on my webpage.

2. Why do you put your JS Code in a separate file?

I put my JavaScript code in a separate file to keep my HTML organized. It is also easier to read, edit, and fix errors in my JavaScript code.

3. How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

I use DevTools by pressing F12 and opening the Console tab. I look for red error messages. I can click an error to find the line number in my JavaScript file and fix the problem. I also use the Network tab to check if submit.json loads correctly.

4. Do your form and fields have the same ids that your JavaScript uses? Does the Console show any errors? List your ids, and fix any errors before you submit.

Yes, my form and fields have matching IDs in my HTML and JavaScript. The IDs used in my JavaScript are signup-form, fullname, email, password, and message. I checked the Console and did not see any red JavaScript errors.
